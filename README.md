# AI Lead Generation Agent

AI-powered lead qualification and outreach automation built with **n8n, Groq, MongoDB, and Gmail**.

## Objective

Automate the lead generation pipeline from lead input to AI qualification, scoring, personalized outreach, response tracking, nurturing, and sales handoff.

## Workflow

**Form Input → Normalize & Validate → MongoDB → Loop Over Items → AI Qualification → Lead Scoring → Human Approval → Gmail Outreach → Response Tracking → Follow-up → Nurture / Sales Handoff / Archive**

## Technologies

* n8n
* Groq
* MongoDB
* Gmail
